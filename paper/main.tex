\begin{abstract}
Walk-based graph learners feed random walks, decorated with random node
features, into a sequence model; recognising a cycle of length $k$ then
reduces to deciding whether the token at time $t$ equals the token at time
$t-k$. We show that this primitive imposes a sharp memory requirement on
linear time-invariant (LTI) state-space models (SSMs): with real state
dimension $S<k$, the Hankel matrix of any lag-$k$ probe has rank at most
$S$ while its target has $k$ unit singular values, so the probe error has
$\mathcal{H}_\infty$ norm at least one and mean-squared error at least
$1/k$; the bound is tight at $S=k$. On circular skip-link (CSL) graphs, where
1-WL message passing is at chance, we compute exactly the non-backtracking
return horizon $W^*(s)$ that separates each class, and an exact-count
estimator with window $S$ recognises every class precisely at $S=W^*(s)$.
Trained diagonal SSMs obey the barrier but pay a large optimisation
overhead: token-level lag detection requires a median of
$\phaseRatioLTI\times$ the Hankel minimum, input-dependent (selective)
dynamics do not escape it, and on CSL the best trained model reaches
\cslLTIBest\% against \cslOrBest\% for the oracle.
\end{abstract}

State-space models, graph neural networks, Hankel operators, expressivity, random walks.

\section{Introduction}
\IEEEPARstart{M}{essage-passing} graph neural networks (GNNs) are bounded
by the 1-dimensional Weisfeiler--Leman (1-WL) test~\cite{xu2019gin,morris2019wl}
and cannot, for instance, separate the regular circular skip-link (CSL)
graphs~\cite{murphy2019rp,dwivedi2023benchmarking}. Walk-based learners
circumvent this by reading random walks as sequences~\cite{toenshoff2023crawl,chen2025neuralwalker},
and random node features make walk revisits observable~\cite{abboud2021rni,sato2021rf}.
With structured state-space models (SSMs)~\cite{gu2022s4,gu2022s4d,gu2024mamba}
now used as the sequence backbone for graphs~\cite{wang2024graphmamba,behrouz2024graphmamba,chen2025neuralwalker},
a basic question arises: \emph{how much state does a walk-based SSM need to
see a cycle?}

CRaWl~\cite{toenshoff2023crawl} fixes an explicit window $s$ and provably
detects cycles up to length $s$; an SSM has no window, only a state. We
answer the question with classical realisation theory~\cite{ho1966kalman}.
Our contributions are:
(i) an exact impossibility result and a tight quantitative bound, via
Hankel-rank and Nehari/AAK arguments~\cite{nehari1957,aak1971,glover1984hankel},
showing that an LTI SSM needs real state $S\ge k$ to probe lag-$k$
revisits;
(ii) an exact, graph-level prediction of the state each CSL class needs,
computed from the non-backtracking return profile~\cite{alon2007nbw};
(iii) experiments separating the \emph{information} barrier from the
\emph{optimisation} overhead of gradient-trained LTI and selective SSMs.
Our results complement the copying lower bounds of~\cite{jelassi2024repeat}
by giving a signal-processing characterisation specific to graph walks.

\section{Problem Setting}
Let $G=(V,E)$ be a graph and $v_0,v_1,\dots,v_T$ a non-backtracking (NB)
walk ($v_{t+1}\ne v_{t-1}$). Each walk receives fresh features
$r_v\sim\mathcal{N}(0,I_d)$, i.i.d.\ over $v$, and the model reads
$x_t=r_{v_t}$. A walk-based SSM with real state $s_t\in\R^S$ is
\begin{equation}
  s_t = A_t s_{t-1} + B_t x_t,\qquad \hat y_t = g(s_t,x_t),
  \label{eq:ssm}
\end{equation}
with arbitrary readout $g$. The model is \emph{LTI} if $A_t\equiv A$,
$B_t\equiv B$, and \emph{selective} if $(A_t,B_t)$ depend on $x_t$ as in
Mamba~\cite{gu2024mamba}. The \emph{lag-$k$ revisit} label is
$y_t=\one[v_t=v_{t-k}]$; on NB walks, $y_t=1$ exactly when the last $k$
steps close an NB cycle, so revisit statistics are cycle statistics.
Because features are continuous, $y_t=\one[x_t=x_{t-k}]$ almost surely.

\section{Theory}
\begin{proposition}[Exact detection]\label{prop:exact}
If $S<k$, then for every LTI pair $(A,B)$ and every readout $g$ there exist
two token sequences with the same $(s_t,x_t)$ but $y_t=1$ and $y'_t=0$.
\end{proposition}
\begin{IEEEproof}
By Cayley--Hamilton, $A^S=\sum_{i=0}^{S-1}c_iA^i$, hence
$A^k=\sum_{i=0}^{S-1}c_iA^{i+k-S}$, where the exponents lie in
$\{k-S,\dots,k-1\}\subseteq\{1,\dots,k-1\}$. Fix any sequence with
$x_{t-k}=x_t$ and any $e\ne 0$. Set $x'_{t-k}=x_{t-k}+e$ and
$x'_{t-j}=x_{t-j}-c_{j-k+S}\,e$ for $j\in\{k-S,\dots,k-1\}$, leaving all
other tokens (including $x_t$) unchanged. Then
$s_t-s'_t=\sum_{j\ge1}A^jB(x_{t-j}-x'_{t-j})=-A^kBe+\sum_i c_iA^{i+k-S}Be=0$,
while $y'_t=0$.
\end{IEEEproof}

Proposition~\ref{prop:exact} is a worst-case statement. The next result
quantifies how badly any linear read-out of the state must fail on
\emph{typical} inputs. A lag-$k$ probe $z_t=c^\top s_t+b^\top x_t$
estimates $w^\top x_{t-k}$ ($\|w\|=1$). Its error
$z_t-w^\top x_{t-k}=\sum_{m\ge0}e_m x_{t-m}$ has impulse response
$e_0=c^\top B+b^\top$ (which can be cancelled by $b$) and
$e_m=c^\top A^mB-\delta_{mk}w^\top$ for $m\ge1$, with transfer function
$E(z)=\sum_{m\ge1}e_mz^{-m}$.

\begin{theorem}[Hankel barrier]\label{thm:hankel}
If $S<k$, every LTI probe satisfies
\begin{align}
 &\textstyle\sup_{\omega}\|E(e^{j\omega})\|\ \ge\ 1, \label{eq:hinf}\\
 &\textstyle\sum_{m=1}^{2k-1}\min(m,2k-m)\,\|e_m\|^2\ \ge\ 1, \label{eq:frob}
\end{align}
and hence, for white unit-variance tokens,
$\E\big[(z_t-w^\top x_{t-k})^2\big]\ge 1/k$. Conversely, for $S=k$ and
every $\varepsilon>0$ there is an LTI probe with mean-squared error below
$\varepsilon$.
\end{theorem}
\begin{IEEEproof}
Let $\mathcal{H}_k(f)$ be the $k\times kd$ block-Hankel section with
$(i,j)$ block $f_{i+j+1}$, $0\le i,j<k$. For the model,
$h_{i+j+1}=(c^\top A^{i})(A^{j+1}B)$, so $\rank\mathcal{H}_k(h)\le S$. The
target $\delta_{m,k}w^\top$ yields a block anti-diagonal matrix with $k$
singular values equal to $\|w\|=1$. By Eckart--Young,
$\|\mathcal{H}_k(e)\|_2\ge\sigma_{S+1}(\mathcal{H}_k(\delta w^\top))=1$.
A finite section is dominated by the Hankel operator norm, which by
Nehari's theorem~\cite{nehari1957} is at most $\|E\|_{\infty}$; this gives~\eqref{eq:hinf}.
Bounding the spectral norm by the Frobenius norm, where $e_m$ occurs
$\min(m,2k-m)$ times, gives~\eqref{eq:frob}; and $\min(\cdot)\le k$ gives
the mean-squared bound. For tightness, take $A=\rho P$ with $P$ the
$k$-cycle permutation, $B=e_1w^\top$, $c=\rho^{-k}e_1$, and $b$ to cancel
$e_0$. Then $e_m=\rho^{m-k}w^\top$ for $m=2k,3k,\dots$ and $0$ otherwise,
so the error is $\rho^{2k}/(1-\rho^{2k})\to0$ as $\rho\to0$.
\end{IEEEproof}

\begin{remark}
The tight construction needs gains of order $\rho^{-k}$, i.e.\ the
near-optimal LTI probe is exponentially ill-conditioned in $k$. This
predicts that gradient-trained SSMs operating near $S=k$ will fall short of
the bound, which is exactly what we observe in Section~\ref{sec:exp}.
Selective SSMs break the factorisation $h_{i+j+1}=(c^\top A^i)(A^{j+1}B)$,
so Theorem~\ref{thm:hankel} does not apply to them; we test them empirically.
\end{remark}

\subsection{Graph-level consequence: NB return horizons}
Let $\rho_G(\ell)=\Pr[v_\ell=v_0]$ for the stationary NB walk. We compute it
exactly from the NB (Hashimoto) operator on directed edges. Theorem~\ref{thm:hankel}
implies that an LTI walk-SSM with state $S$ has (approximate) linear access
to revisits only at lags $\ell\le S$.
For a family $\{G_s\}$ we define the \emph{distinguishability horizon}
\begin{equation}
 W^*(s)=\min\Big\{W:\ \max_{\ell\le W}|\rho_{G_s}(\ell)-\rho_{G_{s'}}(\ell)|>\tau\ \ \forall s'\ne s\Big\},
\end{equation}
with $\tau=2\cdot10^{-3}$. For the ten CSL classes
($n=41$, skip $s\in\{2,3,4,5,6,9,11,12,13,16\}$), $W^*(s)$ ranges from
\cslWmin{} to \cslWmax{} (Table~\ref{tab:csl}). The prediction is that
class $s$ becomes recognisable once $S\ge W^*(s)$.

\section{Experiments}\label{sec:exp}
\textit{Models.} We use one diagonal complex SSM layer with
S4D-Lin initialisation~\cite{gu2022s4d}. It has $\lfloor S/2\rfloor$ complex
modes plus one real mode if $S$ is odd, so its real state dimension is
exactly $S$. The discretisation is $A=\exp(\Delta\Lambda)$ and
$B_t=\Delta\,B$. The \emph{LTI} variant learns $\Delta$ per mode; the
\emph{selective} variant sets $\Delta_t=\mathrm{softplus}(W_\Delta x_t+b)$.
The readout $g$ sees $[\Re s_t,\Im s_t,x_t]$ and comparison features
$(Qx_t-Ks_t)^{\odot2}$, followed by a two-layer MLP. It is a pointwise map
of $(s_t,x_t)$ and is therefore covered by Proposition~\ref{prop:exact}.
Features are $d=8$ dimensional; training uses AdamW with a cosine
schedule. All runs are on CPU, and the code regenerates every figure and
number in this letter.

\textit{Delay realisation.} We first fit the impulse response of an $S$-state
diagonal LTI system to the pure delay $\delta_{m,k}$ ($m\ge1$) by gradient
descent, keeping the best of four restarts (Fig.~\ref{fig:delay}). Below the
bound ($S<k$), the median relative $\ell_2$ error is \delayErrBelow{} (the
minimum is \delayErrMinBelow{}). Above it, the median is \delayErrAbove.
Reaching an error of $0.1$ takes a median of $\delayOverhead\,k$ states,
a first sign of the conditioning overhead predicted by the Remark.

\textit{Token-level phase diagram.} We train on NB walks of length 64 over
256 random 4-regular graphs ($n=24$), built as unions of two Hamiltonian
cycles, and test on 64 unseen graphs. Fig.~\ref{fig:phase} reports test AUROC for the
lag-$k$ revisit label. Below the bound ($S<k$), the mean AUROC is
\phaseAucBelowLTI{} (LTI) and \phaseAucBelowSel{} (selective). For
$S\ge4k$ it is \phaseAucAboveLTI{} and \phaseAucAboveSel. Where an
AUROC of $0.95$ is reached, it takes a median of $\phaseRatioLTI\times$
(LTI) and $\phaseRatioSel\times$ (selective) the Hankel minimum $S=k$.
Selectivity changes AUROC by \phaseSelMinusLTI{} on average (mean absolute
difference \phaseSelMinusLTIabs). Input-dependent dynamics therefore do
not escape the memory requirement, which is consistent with a barrier that is
information-theoretic rather than an artefact of time invariance.

\textit{CSL classification.} Each training example is one NB walk (length
128) on a CSL graph, and the class is predicted from mean-pooled features.
At test time, each graph is judged from 16 walks of length 256. As a
reference we use an \emph{oracle} that applies multinomial logistic
regression to the exact revisit frequencies at lags $1,\dots,S$. This is
the best a window-$S$ reader can do. Figs.~\ref{fig:csl} and~\ref{fig:thr}
and Table~\ref{tab:csl} summarise three seeds. The oracle reaches
\cslOrBest\% and exceeds 95\% from $S=\cslOrOnsetS$. Its per-class onset
equals the predicted $W^*(s)$ for \cslExactOr{} of 10 classes, which confirms
the horizon analysis. The deviations are classes identified by elimination
before their own horizon. Trained walk-SSMs rise above the 10\% 1-WL
level but remain well below the oracle: the best LTI model reaches
\cslLTIBest$\pm$\cslLTIBestStd\% at $S=\cslLTIBestS$, and the best selective
model reaches \cslSelBest$\pm$\cslSelBestStd\% at $S=\cslSelBestS$. Only
\cslClassesLTI{} (LTI) and \cslClassesSel{} (selective) classes reach 80\%
accuracy at any $S\le\cslSmax$. On graphs, therefore, the binding
constraint in practice is not the Hankel capacity but the optimisation of
the precise, ill-conditioned delays that Theorem~\ref{thm:hankel} requires.

%\section{Conclusion}
For walk-based graph learners with LTI state-space backbones, seeing a
cycle of length $k$ costs at least $k$ real state dimensions. This is a
Hankel-rank fact with a tight $\mathcal{H}_\infty$ and mean-squared form.
Combined with exact non-backtracking return horizons, it predicts the
state size at which each CSL class becomes separable, and an exact-count
oracle confirms the prediction. Trained diagonal SSMs, with or without
selectivity, obey the barrier and need several times the minimal state.
This points to the conditioning of delay realisation, rather than capacity
alone, as the practical bottleneck. Natural extensions are
lower bounds for selective SSMs and better-conditioned delay
parameterisations for graph SSMs.
